script.channelsdvr.hub 0.1.3

# Channels DVR Hub 0.1.3 ALPHA for Kodi 21 Omega

The Dashboard refreshes its statistics together without the previous flickering. Cards keep their existing values while a refresh is in progress, and focus and navigation stay stable. One **Last refreshed** timestamp records the last successful statistics refresh.

In **Settings → Dashboard → Automatic statistics refresh**, choose **1, 2, 5, 10, 15 or 30 minutes**, or choose **Disabled**. The default is **5 minutes**. The Dashboard loads statistics once when it first opens on a connected source. An extra startup retrieval has been fixed. **Refresh statistics** is available at any time, including when automatic refresh is disabled.

Install or update through **kcook-lab-repo → Program add-ons → Channels DVR Hub**. The repository install source is [kcook-lab-repo](https://kcook98765.github.io/kcook-lab-repo/).

## Known limitations

On some DVR responses, **DVR Total** displays **Unknown** when the server omits its total. **Storage used** can also display **Unknown** when the server reports disk counters that this version cannot reconcile. [Issue #6](https://github.com/kcook98765/script.channelsdvr.hub/issues/6) tracks both cases.

The Dashboard changes were qualified with read-only operations on Kodi 21.3 Omega. Playback, recording changes and pass management remain outside this release's connected qualification. Channels DVR Hub is an independent, unofficial integration. Use only an authorized DVR and content. Provider authorization for the integration remains unverified.

# Channels DVR Hub 0.1.4 ALPHA for Kodi 21 Omega

The Dashboard now shows one small **Last updated** date and time. It advances after a successful statistics refresh. The cards keep their values while the add-on reads fresh statistics.
